# Scrims Valorant

Scrims Valorant is a backend application built with Java and Spring Boot for organizing competitive Valorant scrims.

The project focuses on object-oriented design, domain modeling, and maintainable software architecture. Players can create scrims, apply to matches, confirm participation, and progress through the different stages of a competitive session.

## Features

* User registration and authentication
* Scrim creation and management
* Player applications and confirmations
* Configurable matchmaking
* Notification integration
* RESTful API architecture

## Design

The application was designed following object-oriented principles, emphasizing clear responsibilities, low coupling, and extensibility.
